🪶 项目简介
砚台记是一款轻量级的电脑使用时光追踪工具。它在后台静默记录你的应用使用时长、活跃时段与专注节奏，并生成一份可视化的「时光报告」——像研墨一样，把你的时间沉淀成看得见的痕迹。
无论你是想了解自己的时间都花在了哪里、优化工作节奏，还是单纯好奇一天的真实专注度，砚台记都能给你一份清晰、安静、不打扰的答案。

+ 🕰️ 自动追踪：无需手动打卡，后台记录前台窗口与应用切换
+ 📊 可视化报告：日 / 周 / 月报，图表化呈现时间去向
+ 🎯 专注分析：识别深度工作时段与频繁打断
+ 🔒 本地优先：数据全部存储在本地，不上传云端
+ 🪶 轻量安静：常驻内存 < 50MB，CPU 占用可忽略
